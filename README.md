\# OOP Student Management System



A simple \*\*Student Management System\*\* built with \*\*C++\*\* to practice Object-Oriented Programming concepts and basic data management.



\## About the Project



This project is a console-based Student Management System that allows the user to manage student information using a `StudentInfo` class and a `vector` to store multiple students.



Each student contains:



\* First Name

\* Last Name

\* ID

\* Age

\* GPA



\## Features



\### Display All Students



Displays the information of all students currently stored in the system.



\### Find Student by ID



Searches for a specific student using their unique ID and displays their information.



\### Add Students



Allows the user to enter and add multiple students to the system.



\### Delete Student by ID



Allows the user to delete a student by entering their ID.



\### Data Validation



The program validates some student information:



\* GPA must be between \*\*0 and 4\*\*.

\* Age must be between \*\*17 and 30\*\*.
